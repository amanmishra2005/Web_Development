## 📂 Repository Breakdown

### 🧱 1. HTML Exercises `HTML/`

Practice layouts using semantic HTML5 structural tags — `<header>`, `<section>`, `<article>`, `<footer>` — plus form validations, tables, and media embeds.

### 🎨 2. Styling & Design `CSS/`

Flexbox, Grid, custom CSS variable tokens, keyframe animations, transitions, and hover interactions — built into responsive templates that adapt gracefully across mobile, tablet, and desktop.

### ⚡ 3. Interactive Scripting `JavaScript/`

Client-side DOM selectors, event listeners, dynamic form handling, and browser storage. Includes API integration testing with JSON requests and `async`/`await`.

### ⚛️ 4. Modern Libraries `React/`

**Core concepts & component practices**

| Folder | Focus |
|---|---|
| `First_React_App/` / `React_Component/` | Fundamental setups — component creation, props usage, Vite integration |
| `Fragments/` | Clean templates using React Fragments to avoid redundant wrapper DOM nodes |
| `Mapping/` | Rendering lists dynamically from data arrays, componentizing list items, CSS Modules (`Container.module.css`) for localized styling, and wrapper components (`Container.jsx` via `props.children`) |
| `BootStrap/` | Integrating Bootstrap for responsive UI components |

**Mini projects** `React/Projects/`

| Project | What it does |
|---|---|
| 📝 **To-Do App** (V1 & V2) | Task creation, display, and deletion using component state |
| 🕐 **Bharat Clock** | Live date and time updates |
| 🧮 **Calculator** | Basic arithmetic processing with custom components |

## 🚀 How to Run Locally

<details open>
<summary><b>Vanilla HTML / CSS / JS</b></summary>
<br>

No build tools needed:

1. Double-click the `.html` file to open it in your browser, **or**
2. Use an editor extension like **VS Code Live Server** for local hot-reloading (e.g. `http://127.0.0.1:5500`)

</details>

<details open>
<summary><b>React Apps</b></summary>
<br>

Each React project is built with Vite. To run any of them:

```bash
cd React/Mapping        # or any other project folder
npm install
npm run dev
```

Then open the URL shown in your terminal (typically `http://localhost:5173`) 🎉

</details>
