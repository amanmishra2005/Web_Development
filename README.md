# Web Development & Design Portfolio

This repository contains my web development projects, styling exercises, and client-side scripting directories. It covers core web design concepts, vanilla layouts, and a personal portfolio project.

---

## 📂 Repository Breakdown

### 1. 💼 Personal Portfolio (`Portfolio_Website/`)
A responsive, single-page personal portfolio website designed from scratch.
*   **Technologies**: Semantic HTML5, Vanilla CSS3 (Custom properties/variables, Flexbox, Media queries).
*   **Files**:
    *   `Portfolio_Website.html`: The structural code highlighting profile bios, project portfolios, educational background, and contact forms.
    *   `Portfolio_Website.css`: The stylesheet governing color tokens, responsive scaling, cards, and custom scroll behaviors.

### 2. 🧱 HTML Exercises (`HTML/`)
*   Practice layouts using HTML5 structural tags (`<header>`, `<section>`, `<article>`, `<footer>`).
*   Form validations, tables, and media embeds.

### 3. 🎨 Styling & Design (`CSS/`)
*   Practices for CSS Flexbox, Grid, custom variable tokens, keyframes, transitions, and hover interactions.
*   Responsive templates adjusting gracefully across mobile, tablet, and desktop monitors.

### 4. ⚡ Interactive Scripting (`JavaScript/`)
*   Client-side JavaScript operations, DOM selectors, event listeners, dynamic form actions, and data storage.
*   API integration testing (JSON requests, async/await).

### 5. ⚛️ Modern Libraries (`React/`)
*   Component-driven structure practices, state management (hooks like `useState`, `useEffect`), and single-page routing structures.

---

## 🚀 How to Run Locally

### Vanilla HTML/CSS/JS (HTML, CSS, JavaScript, Portfolio_Website)
You don't need any complex build configurations. Simply open the `.html` file inside your preferred browser:
1. Double-click the `.html` file (e.g., `Portfolio_Website.html`).
2. Alternatively, use an editor extension like **VS Code Live Server** to run it on a local hot-reloading port (e.g. `http://127.0.0.1:5500`).
